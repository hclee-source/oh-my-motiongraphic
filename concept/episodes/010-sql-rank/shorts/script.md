## 1. 동점이 있을 때
> 화면: 점수 카드 90 · 90 · 85 · 80 → 90 두 장에 ‘공동 1등’ → 85 위에 ‘?’.

1. 90, 90, 85, 80점. | 90점 두 명이 공동 1등입니다.
2. 그다음 85점은 | 몇 등일까요?

## 2. 세 함수
> 화면: 세 줄 — RANK 1 1 3 4 / DENSE_RANK 1 1 2 3 / ROW_NUMBER 1 2 3 4.

3. RANK는 1, 1, 3, 4. | 동점자 수만큼 | 다음 번호를 건너뜁니다.
4. DENSE_RANK는 1, 1, 2, 3. | 건너뛰지 않습니다.
5. ROW_NUMBER는 | 1번, 2번, 3번, 4번. | 동점이어도 다른 번호입니다.

## 3. PARTITION BY
> 화면: 표가 두 묶음으로 나뉘고 묶음마다 1부터.

6. PARTITION BY를 넣으면 | 묶음마다 1부터 다시 셉니다.

## 4. 한 줄 정리
> 화면: 세 줄 정리.

7. 건너뛰면 RANK, | 촘촘하면 DENSE_RANK, | 모두 다르면 ROW_NUMBER.
