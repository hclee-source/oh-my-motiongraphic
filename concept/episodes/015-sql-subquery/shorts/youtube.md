# 015 쇼츠 업로드용 정보

## 제목 (하나 고르기)
- ANY와 ALL, 1분 정리
- ANY는 최솟값, ALL은 최댓값? 부등호 방향까지

## 설명란

서브쿼리가 여러 값을 돌려줄 때 ANY는 통과하기 쉬운 쪽 끝값, ALL은 어려운 쪽 끝값과 비교합니다. 부등호 방향별 정리와 EXISTS까지 1분에 봅니다.

#SQLD #SQL개발자 #서브쿼리 #ANY #EXISTS

## 태그
SQLD, 서브쿼리, ANY, ALL, EXISTS, 쇼츠

## 올릴 때
- ‘관련 동영상’에 본편을 연결한다(공식 업로드 창구로는 지정할 수 없어 스튜디오에서 직접).
