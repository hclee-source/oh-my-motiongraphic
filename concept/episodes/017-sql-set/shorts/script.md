예시 숫자(검수용): 위 결과 3행 — 가, 나, 다 / 아래 결과 6행 — 나, 다, 라, 마, 바, 바(바 두 번) / 양쪽에 있는 값 나 · 다
  UNION ALL 3 + 6 = 9 / UNION 6(가 · 나 · 다 · 라 · 마 · 바) / INTERSECT 2(나 · 다) / 위 MINUS 아래 1(가) / 아래 MINUS 위 3(라 · 마 · 바, 바는 한 번)

## 1. 두 결과
> 화면: 겹친 원 두 개 — 왼쪽 원 ‘위 결과 3행’, 오른쪽 원 ‘아래 결과 6행’ / 왼쪽만 ‘가’, 겹친 칸 ‘나 · 다’, 오른쪽만 ‘라 · 마 · 바 · 바’.

1. 위 SELECT의 결과는 3행, | 아래 SELECT의 결과는 6행입니다.
2. 그중 두 값은 | 양쪽에 모두 있습니다.

## 2. UNION ALL과 UNION
> 화면: 두 원 전체가 칠해지며 ‘3 + 6 = 9행’(겹친 칸 ‘나 · 다’ 옆에 ×2) → ×2와 두 번째 ‘바’가 흐려지며 ‘6행’.

3. UNION ALL은 | 그대로 이어 붙여 | 9행입니다.
4. UNION은 중복을 지워 6행, | 아래 결과 안에서 두 번 나온 값도 | 한 번만 남습니다.

## 3. INTERSECT
> 화면: 겹친 칸 ‘나 · 다’만 밝게 → ‘2행’.

5. INTERSECT는 | 양쪽에 모두 있는 값만 남겨 | 2행입니다.

## 4. MINUS
> 화면: 왼쪽만 칸 ‘가’ → ‘위 MINUS 아래 1행’ / 오른쪽만 칸 ‘라 · 마 · 바’ → ‘아래 MINUS 위 3행’ → 작은 줄 ‘SQL Server는 EXCEPT’.

6. 위에서 아래를 빼는 MINUS는 | 위에만 있는 값, 1행입니다.
7. 거꾸로 아래에서 위를 빼면 3행, | 순서를 바꾸면 결과가 달라집니다.
8. SQL Server에서는 | MINUS 대신 EXCEPT라고 적습니다.

## 5. 규칙
> 화면: SQL 틀 — 위아래 열 개수 같게 → 열 이름은 첫 번째 SELECT → 맨 끝 ORDER BY.

9. 위아래 열 개수는 같아야 하고, | 결과 열 이름은 | 첫 번째 SELECT를 따릅니다.
10. ORDER BY는 | 맨 끝에 한 번만 적습니다.

## 6. 한 줄 정리
> 화면: ‘중복 남김 = UNION ALL’ / ‘중복 지움 = UNION · INTERSECT · MINUS’.

11. 중복을 남기는 건 UNION ALL 하나, | 나머지 셋은 | 중복을 지웁니다.
