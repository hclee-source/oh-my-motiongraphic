## 1. 기출만 외운 수험생
> 화면: 카드 두 장 ‘기출 다시 풀기 100점’ / ‘처음 보는 문제 ?점’ → 점수가 뚝.

1. 기출문제 답을 통째로 외운 수험생이 있습니다.
2. 기출문제를 다시 풀면 100점이 나옵니다.
3. 그런데 처음 보는 문제가 나오자 점수가 뚝 떨어졌습니다.
4. 모델에서도 똑같은 일이 생기는데, 이것을 과대적합이라고 합니다.
5. 오늘은 과대적합과 과소적합, 그리고 둘을 알아보는 법과 줄이는 법을 정리해 보겠습니다.

## 2. 훈련 점수와 검증 점수
> 화면: 데이터 막대가 ‘훈련’과 ‘검증’으로 나뉨 → 연습 점수 / 실전 점수 이름표.

6. 모델은 훈련 데이터로 배우고, 처음 보는 검증 데이터로 실력을 확인합니다.
7. 검증 데이터는 학습에 한 번도 쓰지 않은 데이터여야 합니다.
8. 훈련 데이터 점수는 연습 문제 점수, 검증 데이터 점수는 실전을 미리 보는 점수인 셈이죠.
9. 우리가 정말 원하는 건 실전 점수입니다.
10. 그래서 두 점수를 나란히 놓고 보는 것이 출발점입니다.

## 3. 세 가지 모델
> 화면: 점 그래프(훈련 점 검정, 검증 점 보라 테두리) → 직선, 완만한 곡선, 구불구불한 선이 차례로, 오른쪽에 훈련·검증 성적.

11. 점들이 완만한 곡선을 그리며 놓여 있다고 해 보겠습니다.
12. 첫 번째 모델은 직선 하나로 설명하려고 합니다.
13. 너무 단순해서 훈련 데이터도 제대로 맞히지 못합니다.
14. 훈련 점수도 낮고 검증 점수도 낮은 상태, 이것이 과소적합입니다.
15. 두 번째 모델은 완만한 곡선으로 흐름을 따라갑니다.
16. 훈련 점수와 검증 점수가 둘 다 괜찮습니다.
17. 세 번째 모델은 모든 훈련 점을 빠짐없이 지나는 구불구불한 선입니다.
18. 훈련 데이터의 오차는 0이지만, 점들의 우연한 흔들림까지 외워 버렸습니다.
19. 그래서 새로운 검증 점에서는 크게 빗나갑니다.
20. 훈련 점수는 높은데 검증 점수가 낮은 상태, 이것이 과대적합입니다.

## 4. 복잡도와 오차 곡선
> 화면: 가로 ‘모델 복잡도’, 세로 ‘오차’. 훈련 오차는 계속 내려가고 검증 오차는 U자 → 가장 낮은 곳 표시 → 왼쪽 과소적합, 오른쪽 과대적합.

21. 모델을 점점 복잡하게 만들면 오차는 어떻게 변할까요?
22. 훈련 오차는 복잡해질수록 계속 줄어듭니다.
23. 검증 오차는 처음엔 같이 줄다가, 어느 지점부터 다시 늘어납니다.
24. 검증 오차가 가장 낮은 곳이 알맞은 복잡도입니다.
25. 그보다 왼쪽은 과소적합, 오른쪽은 과대적합 구간입니다.
26. 두 오차 사이의 틈이 벌어지기 시작하면 과대적합을 의심하면 됩니다.

## 5. 편향과 분산
> 화면: 과녁 두 개 — 한쪽으로 몰린 화살(편향 큼), 넓게 흩어진 화살(분산 큼).

27. 이 현상은 편향과 분산이라는 말로도 설명합니다.
28. 편향은 모델이 너무 단순해서 생기는, 늘 한쪽으로 치우친 오차입니다.
29. 분산은 훈련 데이터가 조금만 바뀌어도 모델이 크게 달라지는 정도입니다.
30. 과소적합은 편향이 크고, 과대적합은 분산이 큰 상태입니다.
31. 복잡도를 올리면 편향은 줄고 분산은 늘어서, 둘을 한꺼번에 줄이기는 어렵습니다.
32. 이것을 편향과 분산의 트레이드오프라고 부릅니다.

## 6. 과대적합 줄이기
> 화면: 처방 카드 다섯 장이 차례로.

33. 시험에 자주 나오는 건 과대적합을 줄이는 방법입니다.
34. 첫째, 훈련 데이터를 더 많이 모읍니다.
35. 둘째, 변수를 줄이거나 의사결정나무의 가지를 쳐서 모델을 단순하게 만듭니다.
36. 셋째, 릿지나 라쏘 같은 규제로 계수가 너무 커지지 않게 막습니다.
37. 넷째, 신경망이라면 드롭아웃이나 조기 종료를 씁니다.
38. 다섯째, 교차 검증으로 처음 보는 데이터에서의 성능을 확인하며 알맞은 복잡도의 모델을 고릅니다.
39. 반대로 과소적합이라면 더 복잡한 모델을 쓰거나 쓸모 있는 변수를 더해야 합니다.

## 7. 시험장 체크
> 화면: 체크 카드 세 장이 차례로 → 마지막에 작은 카드 ‘과대적합 = 과적합’.

40. 시험장에서 챙길 것 세 가지입니다.
41. 첫째, 훈련 성능은 높은데 검증 성능이 낮으면 과대적합, 둘 다 낮으면 과소적합입니다.
42. 둘째, 과대적합은 분산이 크고, 과소적합은 편향이 큽니다.
43. 셋째, 데이터를 늘리거나 규제를 더하면 과대적합이 줄지만, 모델을 더 복잡하게 하면 오히려 심해집니다.
44. 덧붙여, 과대적합은 과적합이라고도 부릅니다.

## 8. 한 줄 정리
> 화면: 두 줄 정리.

45. 오늘 내용을 한 줄로 정리하면 이렇습니다.
46. 연습 문제만 잘 풀면 과대적합, 둘 다 못 풀면 과소적합, 판단 기준은 처음 보는 데이터의 성적입니다.
