# 019 쇼츠 업로드용 정보

## 제목 (하나 고르기)
- DELETE · TRUNCATE · DROP, 1분 정리
- 다 지우고 ROLLBACK, 살아나는 건 하나뿐

## 설명란

DELETE는 DML이라 커밋 전이면 되돌릴 수 있고, TRUNCATE와 DROP은 DDL이라 되돌릴 수 없습니다. 지우는 명령 세 가지를 1분에 비교합니다.

#SQLD #SQL개발자 #DDL #TRUNCATE #제약조건

## 태그
SQLD, DELETE, TRUNCATE, DROP, 쇼츠

## 올릴 때
- ‘관련 동영상’에 본편을 연결한다(공식 업로드 창구로는 지정할 수 없어 스튜디오에서 직접).
