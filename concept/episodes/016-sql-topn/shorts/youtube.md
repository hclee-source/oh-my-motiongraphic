# 016 쇼츠 업로드용 정보

## 제목 (하나 고르기)
- ROWNUM으로 상위 몇 개 뽑기, 1분 정리
- ROWNUM = 2는 왜 0행일까

## 설명란

ROWNUM은 정렬하기 전에 붙는 번호입니다. 정렬 먼저 하는 법, ROWNUM = 2가 0행인 이유, FETCH FIRST와 WITH TIES를 1분에 정리합니다.

#SQLD #SQL개발자 #ROWNUM #TopN #FETCH

## 태그
SQLD, ROWNUM, Top N, FETCH, 쇼츠
