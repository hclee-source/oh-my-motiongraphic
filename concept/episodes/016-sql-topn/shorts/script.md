  WHERE ROWNUM <= 2 + ORDER BY 점수 DESC → 먼저 읽힌 60, 70만 남아 정렬 → 70, 60 (95 빠짐)

  ROWNUM = 2 → 0행(첫 행이 1을 받고 2가 아니라 탈락, 다음 행도 다시 1 → 모두 탈락)
  (오라클 12c부터) FETCH FIRST 2 ROWS ONLY → 95, 90 (2행) / FETCH FIRST 2 ROWS WITH TIES → 95, 90, 90 (3행)

## 1. 정렬보다 먼저
> 화면: SQL 두 줄 WHERE ROWNUM <= 2 / ORDER BY 점수 DESC + 점수 카드 다섯 장이 읽힌 순서대로 60 · 70 · 95 · 90 · 90 → 앞 두 장에 ROWNUM 1 · 2 → 두 장만 남아 정렬 → 70 · 60으로 자리 바꿈, 95 카드는 흐리게 밖에.

1. ROWNUM은 | 정렬하기 전에 붙는 번호입니다.
2. ROWNUM으로 두 행을 자르고 | ORDER BY를 함께 적으면, | 먼저 읽힌 두 행만 | 정렬됩니다.
3. 95점이 있어도 | 결과는 70점, 60점입니다.

## 2. 인라인 뷰
> 화면: 괄호 카드 안에서 카드가 95 · 90 · 90 · 70 · 60으로 정렬 → 바깥에서 앞 두 장에 ROWNUM 1 · 2 → 95 · 90 ✓.

4. 상위 몇 개를 뽑으려면 | 괄호 안에서 먼저 정렬하고, | 바깥에서 ROWNUM으로 자릅니다.
5. 그러면 결과는 | 95점, 90점입니다.

## 3. ROWNUM = 2
> 화면: SQL 줄 WHERE ROWNUM = 2 → 카드마다 ‘1’이 붙었다가 ✕ → ‘0행’.

6. ROWNUM = 2는 | 한 행도 나오지 않습니다.
7. 첫 행은 1번을 받는데 | 2가 아니라 버려지고, | 다음 행이 다시 1번을 받기 때문입니다.

## 4. FETCH FIRST와 WITH TIES
> 화면: 정렬된 카드 95 · 90 · 90 · 70 · 60 → SQL 줄 FETCH FIRST 2 ROWS ONLY(작은 칩 ‘오라클 12c부터’) 두 장 → WITH TIES로 바뀌며 90 한 장 더 → 세 장.

8. 오라클 12c부터 쓰는 | FETCH FIRST 2 ROWS ONLY는 | 정렬한 뒤에 | 딱 두 행을 가져옵니다.
9. WITH TIES로 바꾸면 | 마지막 90점과 같은 행까지 | 세 행입니다.

## 5. 한 줄 정리
> 화면: ‘정렬은 안쪽에서, 번호는 바깥에서’.

10. 정렬은 안쪽에서 먼저, | 번호는 바깥에서 붙입니다.
