## 1. 쓰는 순서와 처리 순서
> 화면: SELECT부터 쓴 SQL 카드 → 처리 순번이 FROM 1부터 붙는다.

1. SQL은 SELECT부터 쓰지만, | 처리는 FROM부터 합니다.
2. FROM, WHERE, GROUP BY, | HAVING, SELECT, ORDER BY.

## 2. 별칭
> 화면: 여섯 칸 순서 — SELECT(5) 칸에서 별칭이 생김 → WHERE(2) ✕, ORDER BY(6) ✓.

3. SELECT에서 붙인 별칭은 | 다섯 번째에야 생깁니다.
4. 그래서 WHERE에서는 오류, | ORDER BY에서는 됩니다.

## 3. WHERE와 HAVING
> 화면: WHERE = 행을 거른다 / HAVING = 묶음을 거른다.

5. WHERE는 묶기 전의 행을, | HAVING은 묶은 뒤의 | 묶음을 거릅니다.
6. 그래서 COUNT, AVG 같은 | 집계 함수 조건은 | HAVING에 적습니다.
