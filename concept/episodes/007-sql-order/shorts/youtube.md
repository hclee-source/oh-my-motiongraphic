# 007 쇼츠 업로드용 정보

## 제목 (하나 고르기)
- SQL 실행 순서, 1분 정리
- SELECT 별칭, WHERE에서 쓰면 오류인 이유

## 설명란

SQL은 SELECT부터 쓰지만 처리는 FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY 순서입니다. 그래서 SELECT에서 붙인 별칭은 WHERE에서는 쓸 수 없고 ORDER BY에서는 쓸 수 있습니다.
