# 008 쇼츠 업로드용 정보

## 제목 (하나 고르기)
- NULL의 함정 세 가지, 1분 정리
- NOT IN에 NULL이 있으면 결과는 0행

## 설명란

COUNT(*)는 NULL인 행도 세지만 COUNT(열)은 빼고 셉니다. NULL은 ‘= NULL’이 아니라 IS NULL로 찾고, NOT IN 목록에 NULL이 하나라도 있으면 결과는 0행입니다.

#SQLD #SQL개발자 #NULL #NVL #NOTIN

## 태그
SQLD, NULL, IS NULL, NOT IN, 쇼츠

## 올릴 때
- ‘관련 동영상’에 본편을 연결한다(공식 업로드 창구로는 지정할 수 없어 스튜디오에서 직접).
