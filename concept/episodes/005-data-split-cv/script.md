## 1. 공부한 문제로 시험을 보면
> 화면: 모의고사 카드 → 같은 문제로 채점 → ‘100점?’ 물음표.

1. 모의고사 문제로 공부하고, 같은 문제로 실력을 재면 어떻게 될까요?
2. 점수는 좋게 나오겠지만, 진짜 실력이라고 할 수는 없습니다.
3. 모델도 마찬가지라서, 배울 때 쓴 데이터로 평가하면 안 됩니다.
4. 오늘은 데이터를 나누는 법, 홀드아웃과 교차 검증, 그리고 부트스트랩을 알아보겠습니다.
5. 부트스트랩에 나오는 36.8퍼센트라는 숫자도 직접 계산해 보겠습니다.

## 2. 훈련, 검증, 테스트
> 화면: 막대 하나가 600 / 200 / 200 세 칸으로 나뉘고 이름표 ‘학습’, ‘모델 고르기’, ‘마지막 한 번’.

6. 데이터는 보통 세 덩어리로 나눕니다.
7. 훈련 데이터로 모델을 학습시킵니다.
8. 검증 데이터로 여러 모델이나 설정을 비교해서 하나를 고릅니다.
9. 테스트 데이터는 마지막에 딱 한 번, 고른 모델의 최종 성능을 잴 때만 씁니다.
10. 예를 들어 1000개라면 600개, 200개, 200개처럼 나누는 식입니다.
11. 테스트 데이터를 보고 모델을 고치기 시작하면, 테스트 점수도 더는 믿을 수 없게 됩니다.

## 3. 홀드아웃
> 화면: 같은 막대를 세 번 다르게 나눈 줄 → 점수 0.88 / 0.79 / 0.83처럼 들쭉날쭉.

12. 데이터를 한 번 나눠 평가하는 방법을 홀드아웃이라고 합니다.
13. 간단하고 빠르다는 것이 장점입니다.
14. 하지만 어떻게 나뉘었느냐에 따라 결과가 들쭉날쭉합니다.
15. 우연히 쉬운 데이터만 검증 쪽에 들어가면 점수가 좋게 나오니까요.
16. 그리고 검증 데이터만큼은 학습에 쓰지 못한다는 아쉬움도 있습니다.

## 4. k-겹 교차 검증
> 화면: 막대 하나를 다섯 조각으로 → 다섯 줄, 줄마다 다른 조각이 보라(검증) → 점수 0.82, 0.85, 0.80, 0.84, 0.84 → 평균 0.83.

17. 이 문제를 줄이는 방법이 k-겹 교차 검증입니다.
18. 데이터를 k개의 조각으로 똑같이 나눕니다.
19. k가 5라면, 1000개를 200개씩 다섯 조각으로 나누는 거죠.
20. 첫 번째 조각으로 검증하고, 나머지 네 조각으로 학습합니다.
21. 다음에는 두 번째 조각으로 검증하고, 이렇게 다섯 번 되풀이합니다.
22. 다섯 번의 점수가 0.82, 0.85, 0.80, 0.84, 0.84였다면, 평균 0.83이 최종 점수입니다.
23. 모든 데이터가 한 번씩은 검증에 쓰이니, 나누는 운에 덜 흔들립니다.
24. 대신 모델을 k번 학습해야 하니 시간이 그만큼 더 듭니다.

## 5. LOOCV
> 화면: 점 1000개 줄 → 하나만 보라로 빠지고 나머지 999개로 학습 → ‘1000번’.

25. k를 데이터 개수만큼 키우면 어떻게 될까요?
26. 매번 딱 하나만 빼서 검증하고, 나머지 전부로 학습합니다.
27. 이것을 LOOCV, 하나씩 빼는 교차 검증이라고 합니다.
28. 데이터가 1000개면 모델을 1000번 학습해야 하죠.
29. 데이터를 거의 다 학습에 쓰는 대신, 계산이 아주 많이 듭니다.

## 6. 부트스트랩
> 화면: 공 5개 주머니 → 꺼냈다가 다시 넣기를 다섯 번 → 뽑힌 공·안 뽑힌 공 → (4/5)⁵ ≈ 0.33 → 0.368.

30. 마지막은 부트스트랩입니다.
31. 데이터에서 하나를 뽑아 기록하고, 다시 넣은 뒤 또 뽑습니다.
32. 이렇게 데이터 개수만큼 뽑는 것을 복원 추출이라고 합니다.
33. 다시 넣으니 같은 데이터가 여러 번 뽑히기도 하고, 한 번도 안 뽑히는 데이터도 생깁니다.
34. 한 번도 안 뽑힌 데이터는 따로 모아 검증에 씁니다.
35. 그럼 어떤 데이터가 한 번도 안 뽑힐 확률은 얼마일까요?
36. 한 번 뽑을 때 그 데이터가 아닐 확률은 1 빼기 n분의 1입니다.
37. n번 뽑는 동안 계속 아니어야 하니, 이것을 n번 곱합니다.
38. 데이터가 5개면 5분의 4를 다섯 번 곱해 약 0.33입니다.
39. 데이터가 많아질수록 이 값은 약 0.368, 36.8퍼센트에 가까워집니다.
40. 그래서 부트스트랩에서는 원래 데이터의 약 63.2퍼센트가 한 번 이상 뽑혀 학습에 쓰이고, 36.8퍼센트가 검증에 남습니다.

## 7. 시험장 체크
> 화면: 체크 카드 세 장이 차례로 → 마지막에 작은 카드 ‘층화 k-겹: 범주 비율 맞추기’.

41. 시험장에서 챙길 것 세 가지입니다.
42. 첫째, 테스트 데이터는 모델을 고를 때 쓰지 않고, 마지막 평가에만 씁니다.
43. 둘째, k-겹 교차 검증은 k번 학습하고, 모든 데이터가 한 번씩 검증에 쓰입니다.
44. 셋째, 부트스트랩은 복원 추출이고, 한 번도 안 뽑힐 확률은 약 36.8퍼센트입니다.
45. 덧붙여, 분류 문제에서는 조각마다 범주 비율을 똑같이 맞추는 층화 k-겹 교차 검증을 쓰기도 합니다.

## 8. 한 줄 정리
> 화면: 세 줄 정리.

46. 오늘 내용을 한 줄로 정리하면 이렇습니다.
