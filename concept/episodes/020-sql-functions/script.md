개념: 단일 행 함수 결과 맞히기 — 문자·숫자·날짜 함수, DECODE·CASE (SQLD 2과목 SQL 기본 함수)
시험: SQLD
제목 후보:
  - ROUND(125, -1)은 125일까? 단일 행 함수 결과 맞히기 | SQLD
  - SUBSTR 음수 위치부터 CASE의 ELSE까지, 함수 함정 모음 | SQLD
  - CEIL(-1.5)는 -1일까 -2일까? 함수 결과 맞히기 | SQLD
썸네일 문구: 윗줄 ‘ROUND(125, -1)’ / 오해 ‘125?’ / 띠 ‘함수 결과 맞히기 한 번에’
예시 숫자(검수용): 모두 오라클 기준, SELECT 식 FROM DUAL. 검증 스크립트 verify_examples.py(오라클 규칙을 파이썬으로 구현해 단언 + sqlite3로 교차 확인).
  첫 장: ROUND(125, -1) = 130 (자릿수 -1 = 십의 자리까지 남김, 일의 자리 5에서 반올림. 오라클 ROUND는 0.5를 0에서 먼 쪽으로 → 130. 파이썬 round(125, -1)은 은행가 반올림이라 120이 나오므로 쓰지 않음)
  SUBSTR(문자, 시작, 길이), 위치는 1부터: SUBSTR('ABCDE', 2, 3) = 'BCD' / 시작이 음수면 뒤에서 셈(길이 5 − 3 + 1 = 3번째): SUBSTR('ABCDE', -3, 2) = 'CD'
  INSTR('BANANA', 'A', 1, 2) = 4 (A는 2, 4, 6번째 자리, 1번째 자리부터 찾아 두 번째 A) / 없으면 0 (예: INSTR('BANANA', 'X') = 0, 화면·내레이션은 규칙만)
  LENGTH('SQL 함수') = 6 (S, Q, L, 공백, 함, 수 — 글자 수 기준, 한글 한 음절 = 1) / 오라클은 '' = NULL → LENGTH('') = NULL
  LPAD('7', 3, '0') = '007' (3은 전체 길이, 0은 두 개만 붙음) / LTRIM('xxAxx', 'x') = 'Axx' / REPLACE('S-Q-L', '-') = 'SQL' (세 번째 인수 생략 = 지움)
  자릿수: 1 = 소수 첫째 자리, 0 = 일의 자리, -1 = 십의 자리까지 남김. ROUND(123.456, 1) = 123.5 / TRUNC(129, -1) = 120 (130 아님)
  CEIL(-1.5) = -1 (크거나 같은 가장 작은 정수) / FLOOR(-1.5) = -2 (작거나 같은 가장 큰 정수)
  날짜(하루 = 1): SYSDATE = 지금 날짜와 시각, 2026-11-05 09:00으로 가정 → SYSDATE + 1 = 11월 6일 09:00 / SYSDATE + 1/24 = 11월 5일 10:00
    TO_DATE('20261105', 'YYYYMMDD') − TO_DATE('20261101', 'YYYYMMDD') = 4 (일수, 숫자)
  DECODE(30, 10, '영업', 20, '개발') = NULL (기본값 없음) / DECODE(30, 10, '영업', 20, '개발', '기타') = '기타'
  단순 CASE: CASE 30 WHEN 10 THEN '영업' WHEN 20 THEN '개발' END = NULL (ELSE 없음)
  검색 CASE, 점수 95: CASE WHEN 점수 >= 80 THEN '보통' WHEN 점수 >= 90 THEN '우수' ELSE '노력' END = '보통' (처음 참인 WHEN에서 멈춤)
  SQL Server 이름(한 줄): SUBSTR → SUBSTRING, INSTR → CHARINDEX, LENGTH → LEN, CEIL → CEILING, SYSDATE → GETDATE / DECODE는 오라클 전용 → SQL Server는 CASE
  (검수 반영: MOD 문항은 뺌)
상태: 검수 반영·장면 완성, 렌더 대기 (2026-11-09)

## 1. 결과를 맞혀 보세요
> 화면: 어두운 SQL 카드 ‘SELECT ROUND(125, -1) FROM DUAL;’ → 옆에 ‘?’ 칩 → ‘125’ 칩이 떴다가 ✕ → 결과 칩 ‘130’(보라) → 아래 작은 칩 ‘단일 행 함수 = 행마다 결과 하나’(옆에 흐리게 ‘집계 함수 = 여러 행 → 하나’), ‘DUAL = 식을 계산해 보는 한 행짜리 표’.

1. 125를 ROUND로 반올림하면서, 두 번째 인수에 -1을 넣었습니다.
2. 소수점 아래가 없으니, 결과도 그대로 125일까요?
3. 정답은 130입니다.
4. 자릿수 -1은 십의 자리까지 남기라는 뜻이라, 일의 자리 5에서 반올림하기 때문입니다.
5. 여러 행을 하나로 줄이는 집계 함수와 달리, 이렇게 행마다 결과 하나를 돌려주는 함수를 단일 행 함수라고 합니다.
6. 오늘은 문자, 숫자, 날짜, 조건 순서로 단일 행 함수의 결과를 맞혀 보겠습니다.
7. 예시는 모두 식을 계산해 보는 한 행짜리 표, DUAL에서 실행합니다.

## 2. SUBSTR
> 화면: 글자 칸 A · B · C · D · E(위에 위치 1~5) + SQL 카드 ‘SELECT SUBSTR('ABCDE', 2, 3) FROM DUAL;’ → ‘?’ → B · C · D 칸이 보라로 밝아지며 결과 칩 ‘BCD’ → 카드가 ‘SUBSTR('ABCDE', -3, 2)’로 바뀌고 글자 칸 아래에 -5~-1 번호 → -3(C)에 표시 → C · D 칸 → ‘CD’.

8. 먼저 문자열을 자르는 SUBSTR에 ‘ABCDE’, 그리고 2와 3을 넣으면 무엇이 나올까요?
9. 정답은 BCD입니다.
10. 위치는 1부터 세고, 세 번째 인수는 끝 위치가 아니라 자를 글자 수입니다.
11. 이번에는 시작 위치에 -3, 길이에 2를 넣으면 어떨까요?
12. 정답은 CD입니다.
13. 시작 위치가 음수면 뒤에서 세어, 뒤에서 세 번째 글자 C부터 오른쪽으로 두 글자를 자릅니다.

## 3. INSTR과 LENGTH
> 화면: 글자 칸 B · A · N · A · N · A(위에 1~6) + SQL 카드 ‘INSTR('BANANA', 'A', 1, 2)’ → ‘?’ → 첫 A(2) 회색, 둘째 A(4) 보라 → 결과 칩 ‘4’ → 작은 칩 ‘없으면 0’ → 카드 ‘LENGTH('SQL 함수')’ → 글자 칸 S · Q · L · 공백 · 함 · 수에 1~6 → ‘6’ → 카드 ‘LENGTH('')’ → 회색 ‘NULL’ 칩.

14. 위치를 찾는 INSTR에 ‘BANANA’와 ‘A’, 그리고 1과 2를 넣으면 결과는 무엇일까요?
15. 정답은 4입니다.
16. 1은 찾기 시작할 위치, 2는 두 번째로 나오는 A를 찾으라는 뜻입니다.
17. 찾는 문자가 없으면 오류가 아니라 0을 돌려줍니다.
18. LENGTH로 ‘SQL 함수’의 길이를 재면 얼마일까요?
19. 정답은 6입니다.
20. 가운데 공백도, 한글 한 음절도 한 글자로 셉니다.
21. 덧붙여 오라클은 빈 문자열을 NULL로 보아서, 그 LENGTH도 0이 아니라 NULL입니다.

## 4. LPAD · LTRIM · REPLACE
> 화면: SQL 카드 세 줄이 차례로 — ‘LPAD('7', 3, '0')’ → ‘?’ → ‘007’(앞의 0 두 개만 보라) / ‘LTRIM('xxAxx', 'x')’ → ‘?’ → ‘Axx’(왼쪽 x 두 개가 지워지는 모습) / ‘REPLACE('S-Q-L', '-')’ → ‘?’ → ‘SQL’. 설명이 끝난 줄은 흐리게.

22. LPAD로 ‘7’의 왼쪽을 ‘0’으로 채우는데, 두 번째 인수가 3이면 결과는 무엇일까요?
23. 정답은 007입니다.
24. 3은 붙일 개수가 아니라, 다 채운 뒤의 전체 길이입니다.
25. LTRIM으로 ‘xxAxx’에서 ‘x’를 지우면 무엇이 남을까요?
26. 정답은 Axx입니다.
27. LTRIM은 왼쪽만 지우고, 오른쪽은 RTRIM, 양쪽은 TRIM이 지웁니다.
28. REPLACE에 찾을 문자 하이픈만 적고, 바꿔 넣을 문자는 적지 않으면 어떻게 될까요?
29. 세 번째 인수를 생략하면 찾은 문자를 지우기 때문에, 정답은 SQL입니다.

## 5. ROUND와 TRUNC
> 화면: 자리 눈금 — 숫자 1 2 3 . 4 5 6 아래에 자릿수 -2 · -1 · 0 · 1 · 2 · 3 → SQL 카드 ‘ROUND(123.456, 1)’ → ‘?’ → ‘123.5’ → ‘TRUNC(129, -1)’ → ‘?’ → ‘130’ 칩에 ✕ → ‘120’.

30. ROUND와 TRUNC의 자릿수는, 1이면 소수 첫째 자리, 0이면 일의 자리, -1이면 십의 자리까지 남깁니다.
31. ROUND에 123.456과 1을 넣으면 무엇일까요?
32. 정답은 소수 둘째 자리에서 반올림한 123.5입니다.
33. 그러면 TRUNC에 129와 -1을 넣으면 어떨까요?
34. 정답은 130이 아니라 120입니다.
35. TRUNC는 반올림 없이 버리기만 해서, 일의 자리가 9여도 올라가지 않습니다.

## 6. CEIL과 FLOOR
> 화면: 수직선 -2 · -1.5 · -1 · 0 → SQL 카드 ‘CEIL(-1.5)’ → ‘?’ → 오른쪽 화살표로 ‘-1’ → ‘FLOOR(-1.5)’ → 왼쪽 화살표로 ‘-2’.

36. CEIL에 -1.5를 넣으면 결과는 무엇일까요?
37. 정답은 -1입니다.
38. CEIL은 크거나 같은 가장 작은 정수라서, 음수에서는 0 쪽으로 올라갑니다.
39. 반대로 FLOOR는 작거나 같은 가장 큰 정수라서 -2입니다.

## 7. 날짜 계산
> 화면: 칩 ‘SYSDATE = 지금 날짜와 시각’ → ‘11월 5일 09:00’ → SQL 카드 ‘SYSDATE + 1’ → ‘?’ → ‘11월 6일 09:00’ → ‘SYSDATE + 1/24’ → ‘11월 5일 10:00’ → 카드 두 줄 ‘TO_DATE('20261105', 'YYYYMMDD') - TO_DATE('20261101', 'YYYYMMDD')’ → 결과 칩 ‘4’(일수).

40. 날짜 계산에서는 하루가 1입니다.
41. SYSDATE는 지금 날짜와 시각입니다.
42. 지금이 11월 5일 오전 9시일 때, SYSDATE에 1을 더하면 언제일까요?
43. 정답은 하루 뒤 같은 시각, 11월 6일 오전 9시입니다.
44. 24분의 1을 더하면 한 시간 뒤인 오전 10시가 됩니다.
45. TO_DATE로 문자를 날짜로 바꾼 두 날짜끼리 빼면, 사이의 일수가 숫자로 나옵니다.
46. 11월 5일에서 11월 1일을 빼면 4입니다.

## 8. DECODE와 CASE
> 화면: SQL 카드 ‘DECODE(30, 10, '영업', 20, '개발')’ — 10 → 영업, 20 → 개발 짝에 밑줄 → ‘?’ → 회색 ‘NULL’ 칩 → 카드 끝에 ‘, '기타'’가 붙으면 결과 칩 ‘기타’ → 아래에 단순 CASE 카드 ‘CASE 30 WHEN 10 THEN '영업' WHEN 20 THEN '개발' END’ → 회색 ‘NULL’.

47. 조건 함수 DECODE에 30을 주고, 10이면 영업, 20이면 개발이라고 적으면 결과는 무엇일까요?
48. 정답은 NULL입니다.
49. 30과 같은 값이 없는데, 맨 끝에 기본값도 적지 않았기 때문입니다.
50. 끝에 ‘기타’를 하나 더 적으면 결과는 ‘기타’가 됩니다.
51. CASE 뒤에 값을 바로 두는 단순 CASE도, ELSE가 없으면 똑같이 NULL입니다.

## 9. 검색 CASE
> 화면: 검색 CASE 카드 네 줄 ‘CASE WHEN 점수 >= 80 THEN '보통' / WHEN 점수 >= 90 THEN '우수' / ELSE '노력' / END’ + 칩 ‘점수 = 95’ → ‘?’ → 첫 WHEN 줄만 밝게 → ‘보통’, ‘우수’ 칩에 ✕.

52. 이번에는 WHEN마다 조건을 적는 검색 CASE입니다.
53. 점수가 95일 때, 이 CASE의 결과는 무엇일까요?
54. 정답은 우수가 아니라 보통입니다.
55. CASE는 위에서부터 보다가 처음 참이 되는 WHEN에서 멈추는데, 95는 첫 줄에서 이미 참이기 때문입니다.

## 10. 시험장 체크
> 화면: 체크 카드 세 장이 차례로 → 마지막에 작은 카드 ‘SQL Server’ — SUBSTRING · CHARINDEX · CEILING · GETDATE · LEN(오라클 이름과 짝) + ‘DECODE → CASE’.

56. 시험장에서 챙길 것 세 가지입니다.
57. 첫째, SUBSTR의 위치는 1부터, 세 번째 인수는 길이, 음수 위치는 뒤에서부터 셉니다.
58. 둘째, 자릿수 -1은 십의 자리까지 남기고, TRUNC는 버리기만 합니다.
59. 셋째, DECODE의 기본값이나 CASE의 ELSE가 없으면, 맞는 값이 없을 때 NULL이 나옵니다.
60. 덧붙여, SQL Server의 함수 이름은 SUBSTRING, CHARINDEX, CEILING, GETDATE, 그리고 길이를 재는 LEN입니다.
61. DECODE는 오라클에만 있어서, SQL Server에서는 CASE로 적습니다.

## 11. 한 줄 정리
> 화면: 네 칸 — 문자 ‘위치는 1부터’ · 숫자 ‘-1은 십의 자리’ · 날짜 ‘하루 = 1’ · 조건 ‘없으면 NULL’.

62. 오늘 내용을 한 줄로 정리하면 이렇습니다.
63. 위치는 1부터, 자릿수 -1은 십의 자리, 날짜는 하루가 1이고, 맞는 조건이 없으면 NULL입니다.
