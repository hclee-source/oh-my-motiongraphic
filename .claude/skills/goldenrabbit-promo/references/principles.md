# 모션그래픽 설계 원칙 (요약)

출처는 레퍼런스 영상(쌩초 컴퓨터실, qi3DHzhUSjs)의 자막 분석과 화면 분석이다. 전문은 `research/MOTION_DESIGN_PRINCIPLES.md`에 있다.
v1(editorial-gold)은 A·B·C만, v2(bold-beat)는 E까지 모두 적용했다.

## A. 무엇을 지시하나 (자막에서 도출)
1. **키네틱 타이포가 주인공이다.** 메시지는 글자가 움직이며 전한다. 표지는 소품이다.
2. **도형을 섞는다.** 원·링·사각·헤어라인·방사선이 비트의 타악기 역할을 한다.
3. **팔레트는 베이스 2색 + 포인트 1색으로 제한한다.** 표지의 색이 이미 많으므로 UI 색을 더 늘리지 않는다.
4. **음악은 상업적으로 무료인 경쾌한 곡을 먼저 확보한다.** 영상 길이를 음악에 맞춘다.
5. **모든 컷과 등장을 실제 타격음 시각에 맞춘다.** 기준은 audiomap의 events와 key_moments다.
6. **화면비, 길이, fps를 명시한다.** 레이아웃과 장면 밀도가 여기서 정해진다.
7. **최대 능력을 요구한다.** 장면마다 다른 모션 시스템을 쓴다.

## B. 어떤 순서로 하나
음악 → 소스 수집(사이트, 링크) → 장면 계획(스토리보드) → 장면별로 무엇을 넣을지 지정 → 부분 수정 → 30fps 렌더.

## C. 모션 디테일
- 표지는 **포물선**으로 퇴장한다: x 이동 + y 호 + 약간의 회전. 직선 슬라이드는 쓰지 않는다.
- **피날레 팝**: 마지막 타격음들에 맞춰 요소를 한꺼번에 터뜨린 뒤 로고로 수렴한다.

## E. 화면에서만 보이는 시각 원칙 (자막에는 없음)
| # | 원칙 | 구현 힌트 |
|---|---|---|
| E1 | 1~2비트마다 배경 레지스터를 0ms에 뒤집는다 | `tl.set(bg,{backgroundColor})`를 킥 시각에 둔다 |
| E2 | 라벨 박스: 핵심 단어를 솔리드 사각형에 넣는다 | scaleX 0→1, 약 0.12s, transform-origin left |
| E3 | 영문/한글 짝 칩 | "되네? / IT WORKS?" |
| E4 | 한 단어 안에서 서체를 섞는다 | 대문자 Archivo Black + 소문자 Playfair italic. 한글은 400/800 대비 |
| E5 | HUD 크롬: 모서리 라벨, 타임코드, 눈금자, 티커 | `make_hud.py`가 자동 생성 |
| E6 | 화면을 넘는 초대형 타이포, 세로 회전 단어 | `data-layout-allow-overlap` 표시 |
| E7 | 반복 텍스트 마퀴: 아웃라인과 채움 교차, 행마다 반대 방향 | 오프셋은 타임라인 tween으로 |
| E8 | 빠른 이동에 잔상 | 복제본 2~3개, 불투명도 0.35/0.2/0.1 |
| E9 | 기하 도형 컨페티 ●■▲○✕◆ | 타격 순간 overshoot로 등장 |
| E10 | 이미지는 회전한 카드로 던진다. 분할 레이아웃, 콜라주 | 하드 오프셋 그림자 |
| E11 | 숫자 카운트업, 진행바 | 모노 서체, 0ms로 숫자 교체 |
| E12 | **컷 밀도가 화려함의 대부분**이다. 텍스처 단어는 1비트에 하나 | 읽어야 하는 문장은 3비트 이상 유지 |
| E13 | 엔딩: 로고 주변 아이콘이 싱크에 맞춰 터진다 | 직접 그린 단순 SVG 라인 아이콘 |

## 하지 않는 것
- 레퍼런스의 카피·브랜드·레이아웃을 그대로 따라 하지 않는다. 기법만 차용한다.
- 표지를 크롭하거나 틴트하지 않고, 표지 위에 텍스트를 얹지 않는다.
- 그라디언트, 글로우, 팔레트 밖 색을 쓰지 않는다.
