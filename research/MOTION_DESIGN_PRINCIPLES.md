# 최적의 모션그래픽을 만드는 설계 원칙

출처: 「초간단 명령어로 차원이 다른 모션그래픽 만들기｜Claude Opus 5.5」 (쌩초 컴퓨터실, 8:08)
원본 자동자막: `transcript.txt` (161줄, 타임스탬프 포함)

자막에서 뽑은 조언을 **프롬프트(무엇을 지시할지)** 와 **프로세스(어떤 순서로 할지)** 로 나누고,
각 원칙을 이번 골든래빗 홍보영상에서 어떻게 적용했는지 함께 적었다.

## A. 프롬프트에 반드시 넣을 7가지 (영상 01:48–03:08)

| # | 원칙 (자막 근거) | 왜 중요한가 | 이번 영상 적용 |
|---|---|---|---|
| 1 | **키네틱 타이포그래피를 중심으로** — "텍스트 중점으로 이루어진 디자인" | 내레이션 없이 메시지가 글자 움직임으로 전달된다 | 모든 장면의 주인공은 대형 한글 타이포(페이퍼로지 ExtraBold). 표지는 타이포를 받쳐 주는 역할 |
| 2 | **도형을 섞는다** — "텍스트만 넣으면 심심할 수 있으니 도형을 적절히 섞어" | 글자만 있으면 화면이 단조롭고 리듬이 약하다 | 로고에서 가져온 골드 원, 헤어라인, 사각 블록, 방사선을 비트 액센트로 사용 |
| 3 | **팔레트를 지정한다** — "블랙이랑 화이트랑 형광 핑크 포인트" | 베이스 2색과 포인트 1색이면 어떤 장면이든 한 작품처럼 보인다 | 잉크 블랙 #0F0E0C · 크림 #F4EFE6 · **브랜드 골드 #CEAE73** (로고에서 직접 추출) |
| 4 | **경쾌한 상업적 무료 음악** — "상업적 무료 음악을 찾아서 넣어" | 음악이 영상의 에너지와 길이를 결정한다 | Mixkit 무료 라이선스 「Golden Storm」(Diego Nava, 129BPM, 보컬 없음) |
| 5 | **모션을 비트에 맞춘다** — "모션을 비트에 딱딱 맞춰" | 싱크가 맞아야 '고퀄리티'로 느껴진다 | 비트 분석기로 98비트·25마디·서지/드롭/하드스톱을 측정해 모든 컷과 등장을 실제 타격음 시각에 고정 |
| 6 | **화면비와 길이를 명시한다** — "가로형은 16:9, 세로형은 9:16 … 원하는 초수" | 레이아웃과 장면 밀도가 여기서 정해진다 | 1920×1080, 46.6초(음악 구간에 맞춤), 30fps |
| 7 | **최대 능력을 요구한다** — "너의 업그레이드된 능력을 보여 줘" | 무난하고 평범한 결과로 끝나지 않게 한다 | 장면마다 서로 다른 모션 시스템을 쓴다(카드 플라이바이, 타일 모자이크, 슬램, 피날레 그리드) |

보조 원칙:
- **내용은 간단히만 줘도 된다** — "어떤 내용이 들어가야 하는지 간단하게 써 주면 나머지 문구는 채워 준다". 이번에는 사이트 도서 목록과 시리즈명만 입력으로 쓰고, 카피는 직접 썼다.
- **레퍼런스는 분위기만 참조** — "너무 똑같이 따라해 달라고 하면 안 되고, 분위기만 참조해서 응용하고 변형". 특정 영상의 룩을 복제하지 않는다.

## B. 제작 프로세스 6단계 (영상 04:32–07:40)

1. **음악부터 잡는다** — "이번에는 음악부터 잡고 시작"하고 "20초에 딱 맞는 걸로". 영상 길이를 음악에 맞춘다(그 반대가 아님).
2. **소스는 링크로 준다** — "포트폴리오 사이트와 인스타그램 링크를 줬어요". 직접 타이핑하는 대신 출처 사이트에서 이미지와 텍스트를 수집한다. → goldenrabbit.co.kr에서 표지 16장과 로고를 수집했다.
3. **장면 이미지와 스토리보드를 먼저 만든다** — "각 장면의 이미지부터 먼저 … 스토리보드를 만들어서 보여 줘". 전체 흐름을 한눈에 본다.
4. **장면마다 무엇을 넣을지 하나하나 지정한다** — "각각 프레임에 어떤 작품들을 넣을 건지 하나하나 지정". 아이콘처럼 사소한 요소는 AI에 맡겨도 된다. → STORYBOARD.md에 프레임별 도서·카피·앵커 시각을 모두 명시했다.
5. **부분별로 수정을 요청한다** — "만들어 주는 대로 쓰지 말고 … 전달력·흡입력 있게 부분별로 수정". 수정은 장면 단위로 한다.
6. **30프레임으로 렌더한다** — "그대로 30프레임 영상 렌더링 해 줘". 스토리보드를 확정한 뒤 렌더해야 가장 빠르다.

## C. 모션 디테일 (영상 06:57–07:24)

- **포물선 퇴장** — "포물선 형태로 빠져나오는 모션". 직선 슬라이드보다 호(arc)를 그리며 빠지는 움직임이 더 생동감 있다. → 표지가 퇴장할 때 x 이동과 y 포물선, 회전을 함께 준다.
- **피날레 팝** — "마지막에는 음악 싱크에 맞게 요소들이 팡 튀어나오게". 마지막 타격음에 요소가 한꺼번에 튀어나오며 끝낸다. → 41.0초 무음 뒤 42.5·43.0·45.3초 킥에 맞춰 표지 그리드와 로고 락업이 튀어나온다.

## E. 화면 분석으로 추가한 시각 원칙 (자막에 없는 내용)

> v1은 자막만 분석했다. 영상 속 데모 구간은 자막에 `[음악]`으로만 남아 있어서, 영상을 내려받아(`reference.mp4`)
> 1초 간격으로 프레임을 직접 확인했다. 근거 컨택트시트는 `ref_frames/A~E_*.jpg`
> (A 0:00–0:31 오프닝, B 3:37–4:31 데모 1·2, C 6:04–6:30, D 6:30–7:28 쇼릴, E 7:40–8:08 엔딩).

| # | 시각 원칙 | 데모에서 관찰한 것 |
|---|---|---|
| E1 | **배경색을 비트마다 통째로 뒤집는다** | 노랑 ↔ 블랙 ↔ 라이트그레이, 핫핑크 ↔ 블랙 ↔ 오프화이트로 1~2비트마다 전체 배경이 0ms에 바뀐다 |
| E2 | **라벨 박스 타이포** | 핵심 단어를 솔리드 사각형 안에 넣는다: "AI"에 핑크 박스, "ONE"에 블랙 박스, "디자인으로"에 블루 박스. 툴 이름은 박스 칩(GPT, CLAUDE…) |

| E7 | **반복 텍스트 텍스처와 마퀴** | "PROMPT EDIT REPEAT" 줄이 좌우 반대로 흐르며 아웃라인과 채움이 교차한다. "DESIGNER DESIGNER…"는 벽지처럼 깐다 |
| E8 | **모션 블러와 잔상** | 빠른 이동에 방향성 블러나 잔상이 붙는다(SHADE, 소리도, 코드) |
| E9 | **기하 도형 컨페티** | ●■▲○✕◆ 같은 기본 도형이 비트에 맞춰 튀어나온다. 블루 유기적 블롭이 떠다니며 타이포와 겹친다 |
| E10 | **이미지는 카드로** | 사진을 살짝 회전한 카드로 흩뿌리고, 왼쪽에 큰 타이포·오른쪽에 미디어를 두는 분할 레이아웃, 콜라주 그리드. 폴더 아이콘에서 카드가 포물선으로 튀어나온다 |
| E11 | **숫자와 데이터** | "18.6K"와 점·스파크 바 차트, "15 YEARS"와 점선 진행바(카운트업) |
| E12 | **속도** | 데모 1·2는 한 비트(약 0.5초)에 단어 하나씩 컷이 넘어간다. 화려함은 대부분 **컷 밀도**에서 나온다 |
| E13 | **엔딩** | 로고 워드마크 주변에 팔레트, 필름릴, 반짝이, 마술봉 같은 아이콘이 음악 싱크에 맞춰 "팡" 터진다 |
